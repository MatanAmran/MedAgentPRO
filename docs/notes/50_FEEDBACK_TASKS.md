# MedAgentPro — משימות מפידבק המרצה

**המקור.** פידבק המרצה על ספר שלב א׳, גרסה 20.9.

**מה יש כאן.** מה המרצה ביקש, בלשונו, ואיפה. **אין כאן בדיקה מול הספר** — היא נעשית בשלב הבא, נקודה-נקודה, ונרשמת בעמודת "מצב".

**13 משימות.** ארבע של תוכן חדש · חמש השלמות · ארבעה תיקוני איורים.

**סגורות: 7 מתוך 13** — מ2, מ3, מ5, מ8 (למעט איור 6), מ11, מ12, מ13.
