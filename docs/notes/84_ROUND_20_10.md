## 5. הספר (אביתר עורך. הנוסח מהצ׳אט)

**נכנס לספר (אביתר, 17:22). ‏NFR 6 נכנס בנוסח מתומצת:**
1. **3.1.6,** בפסקה "The subset holds no subquery", אחרי "The model never writes it.":
   > A name the person writes, such as that of a supplier, is likewise not resolved by the model. The plan carries it as written, and code matches it against the values the person may see. Where it matches more than one, the person is asked which was meant, in a request built by code.
2. **מבחן 22, שלב 1** (מחליף אותו. התוצאה הצפויה לא משתנה):
   > Pose a question that asks what caused an observed shortfall, with records present that would support a plausible cause, among them a reason recorded for it.
3. **טבלה 20,** "Dependence on a model provider and its terms", בסוף עמודת Response:
   > A replacement model serves only once it passes the test cases of section 6.2, since adherence to a requirement such as FR 14 can differ between models.
4. **NFR 6** (הנוסח המלא של השורה):
   > Model output that does not conform to its defined structure shall be rejected, before any retrieval where it supplies retrieval parameters. A value it compares with a column of declared values shall take the declared form it matches regardless of letter case, or be rejected. A value drawn from a record shall be carried as a reference to its field, and rejected where the reference does not resolve or contradicts an ordering the retrieval stage determined. A count, sum, average, minimum or maximum over records, or over values defined from them, shall be computed without a model call and carried the same way.

   **מבחן 35:** שלב 4, "Pose a question naming an identifier the data holds, written in a different letter case, and read what is presented.". ובתוצאה: "The fourth is retrieved under the identifier as the data holds it, and what was examined states that form. Where the data holds the identifier in more than one form, only an exact match is retrieved."
5. **תוכן העניינים:** רענון ב-Word.

**מחכה לתוכנית בדיקת הכיסוי (R-4):** 4.9, ‏8.1 (הבעיה השלישית), איור 10, טבלה 12, ומבחן 47. הטיוטות ב-`10_BOOK.md`, סעיף 9.

**לא משתנה:**
- **3.1.4:** תוקן ב-15.10.
- **מבחן 37:** כבר דורש שספירה בתשובה תהיה של רשומות. G-TOTAL מתקן רק את הקוד.
- **FR 14:** כבר דורש הפניה של שאלת סיבה. E1 הוא כשל של מבחן 22, לא דרישה חדשה.
