# Root Cause Analysis Report

## Primary Causal Explanation

**CONCLUSION: Coordinated brute-force attack campaign targeting SSH and FTP services, with secondary system impact on logrotate functionality**

**Confidence Score: 0.92**

## Analysis

### Attack Pattern Identification

This is a **distributed brute-force authentication attack** with the following characteristics:

1. **SSH Brute-Force Campaign** (Primary Attack Vector)
   - Supporting Evidence: E1, E4, E56, E60, E61
   - 189 SSH authentication failures targeting privileged accounts
   - 89 attempts against root user specifically
   - 25 attempts against guest user
   - Pattern indicates credential stuffing/dictionary attack

2. **FTP Service Exploitation Attempts** (Secondary Attack Vector)
   - Supporting Evidence: E3, E5, E58, E59
   - 15 connection bursts indicating automated scanning
   - 67 "user unknown" errors suggesting username enumeration
   - Coordinated with SSH attacks

3. **Distributed Attack Infrastructure**
   - Supporting Evidence: E27-E55
   - 29 unique source IPs from multiple geographic regions
   - Sources span Asia-Pacific (218.*, 220.*, 210.*), Europe (62.*, 82.*, 217.*), and North America
   - Mix of residential ISPs, hosting providers, and compromised systems

4. **Sustained Campaign Timeline**
   - Supporting Evidence: E7-E26
   - 20-day attack duration (June 14-29)
   - Daily recurring pattern around 04:00 hours (E11-E26)
   - Suggests automated attack scheduling

### Secondary Impact

**Logrotate Failures** (Collateral Damage)
- Supporting Evidence: E2, E6, E57
- 16 abnormal exits likely caused by:
  - System resource exhaustion from attack traffic
  - Log file corruption from rapid write operations
  - Disk I/O contention during attack periods

## Supporting Evidence Chain

**Critical Evidence:** E1, E4, E27-E55, E56, E60
**Corroborating Evidence:** E3, E5, E58, E59, E61
**Temporal Evidence:** E7-E26
**Impact Evidence:** E2, E6, E57

## Recommended Actions

### Immediate (0-24 hours)
1. **Block malicious IPs** - Implement firewall rules for all sources in E27-E55
2. **Disable root SSH login** - Edit `/etc/ssh/sshd_config`: `PermitRootLogin no`
3. **Review active sessions** - Check for any successful compromises: `who`, `last`, `lastb`
4. **Audit user accounts** - Verify no unauthorized accounts created, especially "guest"

### Short-term (1-7 days)
5. **Implement fail2ban** - Auto-block IPs after 3-5 failed attempts
6. **Enable SSH key-only authentication** - Disable password authentication entirely
7. **Restrict FTP access** - Consider disabling FTP or migrate to SFTP
8. **Fix logrotate** - Investigate and repair logrotate configuration (check `/etc/logrotate.conf`)
9. **Deploy rate limiting** - Implement connection throttling for SSH/FTP services

### Long-term (1-4 weeks)
10. **Implement geo-blocking** - If business allows, restrict SSH/FTP to known geographic regions
11. **Deploy IDS/IPS** - Install intrusion detection (Snort, Suricata)
12. **Enable MFA** - Implement two-factor authentication for SSH
13. **Network segmentation** - Move SSH/FTP to non-standard ports or behind VPN
14. **Security monitoring** - Establish SIEM alerting for authentication anomalies
15. **Incident response plan** - Document procedures for future attack scenarios

### Forensic Actions
16. **Preserve logs** - Archive all authentication logs for potential investigation
17. **Check for persistence** - Scan for backdoors, rootkits, modified binaries
18. **Verify system integrity** - Run `rpm -Va` or `debsums` to check file modifications

## Risk Assessment

- **Current Risk Level:** HIGH
- **Compromise Likelihood:** MODERATE (no evidence of successful breach, but sustained pressure)
- **Business Impact:** MEDIUM (service availability risk, potential data breach if successful)

---

**Analyst Note:** The consistent 04:00 timing and distributed source pattern suggests this is an automated botnet operation rather than targeted APT activity. However, the persistence and scale warrant treating this as a serious security incident.
